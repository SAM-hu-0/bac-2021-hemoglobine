# تصحيح بكالوريا 2021 — بنية الهيموغلوبين ووظيفته

Site statique autonome : ouvrez `index.html` dans un navigateur, ou publiez le contenu de ce dossier avec GitHub Pages.

## Activer GitHub Pages

1. Dans le dépôt `SAM-hu-0/bac-2021-hemoglobine`, ouvrez **Settings → Pages**.
2. Dans **Build and deployment**, choisissez **Deploy from a branch**.
3. Choisissez la branche **main** et le dossier **/(root)**, puis cliquez **Save**.
4. Après publication, l'adresse du site sera : `https://sam-hu-0.github.io/bac-2021-hemoglobine/`.

Le site charge Tailwind CSS, Chart.js, Three.js et la police Cairo depuis leurs CDN ; une connexion Internet est nécessaire pour ces ressources.
